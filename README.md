# Snake, Water, Gun Game (Python)

A simple, interactive command-line implementation of the classic **Snake, Water, Gun** game (a variation of Rock, Paper, Scissors) built using Python. 

This project was developed to practice core programming fundamentals, including conditional logic, functions, user input handling, and utilizing built-in Python modules.

______________________________________________________________________

## 🎮 Game Rules
- **Snake vs Water:** Snake drinks the Water (Snake wins).
- **Water vs Gun:** Water splashes the Gun (Water wins).
- **Gun vs Snake:** Gun shoots the Snake (Gun wins).
- **Same Choices:** It's a draw!

_______________________________________________________________________

## 🛠️ Features & Logic Covered
* **Randomized Computer Choices:** Implemented using Python's built-in `random` module (`randint`).
* **Input Normalization:** Used `.lower()` string method to handle variations in user input case.
* **Modular Code:** Structured the core win/loss logic inside a clean, reusable function (`game_win`).
